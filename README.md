# suryamart-data-analysis
Proyek analisis data transaksi e-commerce SuryaMart (tugas studi kasus Harisenin Data Analytics Bootcamp). Mencakup end-to-end data cleaning, penanganan missing values &amp; duplikat, transformasi nested IF clustering usia &amp; pengeluaran, pivot table untuk menjawab 6 pertanyaan bisnis, serta perumusan rekomendasi strategi penjualan berbasis data.
